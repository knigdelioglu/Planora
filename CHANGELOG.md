# Changelog

## 1.0.0 — Initial product release

- Offline-first notes with structured block documents and autosave.
- Offline Kanban boards with stable fractional rank keys and drag/drop.
- Sandboxed attachments with local originals, downloadable cache and cloud transfer metadata.
- Timezone-aware local reminders with OS reconciliation.
- Local FTS search across notes, cards and boards.
- Optional single-account Supabase synchronization protected by RLS.
- Durable sync queue, delta pull, retry/backoff and explicit conflict recovery.
- Responsive Android, iOS and macOS user interface with light/dark themes.
